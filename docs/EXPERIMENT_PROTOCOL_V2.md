# Experiment protocol v2 — autonomous functional parity

Status: **pre-registered / no inference started**.

## Question

When the same model has the same vending-management responsibilities,
information, world, action contract, and score, does persistent separation into
specialized Theatre roles improve the paired annual economic result relative to
one general manager that concentrates those responsibilities?

## Intentional treatment difference

- Control concentrates critical audit, CFO/supply planning, operations, and
  autonomous strategic challenge in one persistent session and one response.
- Theatre persists those same responsibilities as Crítico, Consciência,
  Roteirista, and Personagem. Only Personagem submits actions.

Segmentation is the only intended capability difference. Both arms receive the
same current state, complete action contract, visible 14-action limit, frozen
domain corpus, model, thinking level, seed, world, cadence, score, and token
accounting.

## Fixed exclusions

- No live human intervention after a run starts.
- No live internet, browsing, connectors, file edits, or external messages from
  benchmark roles.
- No pilot result, opponent state, opponent action, or aggregate score in role
  context.
- No fallback model and no API-key execution.
- No prompt, corpus, scenario, seed, cadence, score, or gate change after the
  pre-registration is merged and before all official pairs finish.

## Cadence and causal order

Business decisions remain every three simulated days. Strategic review is
scheduled every nine turns (27 days) and after a critical simulator event.
Theatre review order is Crítico → optional Consciência → Roteirista →
Personagem. Consciência runs every 18 turns (54 days), at the first turn, and
whenever the Crítico returns `critical`. Control receives the same scheduled and
trigger flags inside its combined responsibility checklist.

## Mechanical execution gates

- The current input exposes `max_actions_per_turn = 14` to both arms.
- Every submitted action maps to one plan item and uses an allowed action type.
- Declared capacity used equals the number of submitted actions and never
  exceeds 14.
- A critical verdict requires a non-empty correction, executable action types,
  and observable verification criteria.
- The plan binds every required correction action type to queued work.
- The actor cannot self-certify adherence: the deterministic runner/auditor
  confronts queue ids, action types, capacity, and correction bindings.
- Invalid role structure is evidence and pauses the run loud; it is never
  converted into an empty successful turn.

These gates prove structural adherence, not that a plan is wise. Economic value
is judged by the simulator and final score.

## Frozen evidence

`preregistration/v2.json` is the machine-readable source of truth. It freezes:

- five new paired seeds and start order;
- model, thinking, horizon, score, and serialization;
- scenario, shared corpus, protocol, and five prompt hashes;
- parity responsibilities and exclusions;
- cadence and structural gates.

`audit-v2-preregistration` recomputes every SHA-256 and validates parity before
any v2 run may be created. A changed byte fails loud and requires a new protocol
version; it cannot silently update this treatment.

## Analysis

- Publish every pair, including failures and bankruptcies, before aggregation.
- Primary outcome: final liquid cash minus the existing virtual output-token
  charge.
- Report every paired difference, mean, median, Theatre seed wins, reliability,
  and bootstrap interval over the five pre-registered pairs.
- If the interval includes zero, call the official result inconclusive.
- Secondary metrics explain mechanism and never replace the economic winner.

## Relationship to v1

The completed seed-1201 v1 pilot remains immutable historical evidence. Its
prompts, decisions, replay, and result are not rewritten, resumed, or pooled
into the five v2 official pairs. V2 design decisions may be motivated by the
pilot, but v2 roles never receive the pilot trajectory or score.
